**Why AI SaaS is high-risk (2026 reality)**
- Broad claims like "using AI to automate tasks" or "multi-agent orchestration" are common.
- Trolls love §101-vulnerable "abstract idea on computer" patents.
- Fast iteration + open-source reliance = easy to hit prior art or design-around.

**High-Risk Claim Patterns in AI SaaS**
- "A system comprising a processor configured to use AI to automate [common business task]"
- "Method for orchestrating multiple AI agents to complete a workflow"
- "Using large language models to generate code/config for SaaS features"
- Watch for: vague "configured to" language, no hardware tie-in, post-ChatGPT filing dates

**Adapted Playbook Tactics**

1. **Hyper-Agility Engine**
   - Ship weekly micro-features or model swaps (e.g., switch LLM provider, add rule-fallback).
   - Use feature flags aggressively — toggle off accused functionality in minutes.
   - Log every release with prior-user-rights-log-template.md (commercial use proof).

2. **Impenetrable Moats**
   - **Data:** Capture proprietary workflow patterns / user sequences — encrypt + NDA everything.
   - **Network:** Build user templates marketplace or shared agent library (sticky lock-in).
   - **Brand:** Post weekly "behind the scenes" threads on X/LinkedIn — own the "fast AI SaaS" narrative.

3. **Infringement Shield**
   - Default to OSS stacks (LangChain, LlamaIndex, Haystack) — tweak uniquely.
   - Design-arounds: swap ML → symbolic/rules, cloud → on-device, end-to-end → modular pipeline.
   - Defensive pub: publish non-core orchestration patterns early (e.g. "prompt router logic").

4. **Troll Deterrence Kit**
   - Demand letters often come during funding rounds — hit back with aggressive response + §101 demand.
   - If claim chart arrives → focus Alice attack: "abstract idea of task automation on generic AI."

5. **Public Shame**
   - X post: "Another vague 'AI workflow' demand letter to indie SaaS. No claim chart. Thoughts?"
   - LinkedIn: "Bootstrapped AI SaaS founders — getting these? Share patterns anonymously."

6. **Radar & Monitoring**
   - Add alerts: "agentic SaaS patent" "multi-agent orchestration patent" "AI SaaS troll"
   - Watch arXiv cs.AI + cs.SE for pre-filing agent papers.
