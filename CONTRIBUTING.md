# Contributing to TrollProof Playbook

Thanks for wanting to help make this resource better for bootstrapped founders fighting patent noise.

This repo is intentionally simple: no build step, no CI, no fancy tooling. Just Markdown files that anyone can read, fork, download, or print.

We welcome contributions that keep it that way.

## How to Contribute

1. **Fork the repo**
   Click Fork → work in your copy.

2. **Make changes**
   Edit or add files in these folders only (preferred):

   - `/templates/` — new or improved templates, checklists, response scripts
   - `/resources/` — updated links, keyword lists, case studies
   - `/niches/` — add a new industry-specific file (e.g. `ai-agents.md`, `web3.md`)

   Keep files focused, actionable, and under ~800 words. Use simple Markdown.

3. **Commit clearly**
   Examples of good messages:
   - "Add aggressive demand-letter template with §101 Alice challenge"
   - "Update scan-checklist.md with 2026 USPTO interface changes"
   - "Create niches/biotech.md with gene-editing prior art tips"

4. **Open a Pull Request**
   - Title: Short and descriptive
   - Description: Explain what you added/fixed and why it helps founders
   - Link any related issues if you created one
   - Target the `main` branch

5. **After merge**
   Your change goes live immediately. Star or share the repo if you like it.

## What We Love (and Accept Quickly)

- Better wording / clearer examples
- New templates that solve real pain (e.g. updated Alice arguments for 2026+ cases)
- Anonymized troll stories (redact everything identifying)
- Niche adaptations (e.g. AI image gen patents, quantum computing claims)
- Fixed typos, broken links, outdated advice
- Small PRs (1–3 files)

## What We Usually Reject (Politely)

- Promotion of paid services, alliances, defensive patent networks
- Long legal essays or theory — keep it actionable
- Code, apps, or build steps — this is a static Markdown repo
- Spam or off-topic additions
