# Weekly Agility Checklist
TrollProof Playbook – Hyper-Agility Engine

Goal: Ship meaningful updates so fast that any patent assertion becomes obsolete before litigation even starts (typical timeline: 18–36 months).

Run this checklist every Friday (or your reset day). Time estimate: 15–30 minutes.

Mark [ ] as you complete each item.

## 1. Progress Review (5 min)
- [ ] Did we ship at least one user-facing improvement, bug fix, or experiment this week?
  - Examples: new feature toggle, UI tweak, model fine-tune, onboarding copy change
  - If no → What blocked us? Fix next week.
- [ ] How many users actively tested / gave feedback on the latest version?
  - Goal: at least 5–10 real interactions (even if small user base)
- [ ] Did we log any new user data/insights that improve our proprietary edge?
  - (trade secret fuel — never expose publicly)

## 2. Pivot Readiness Check (5 min)
- [ ] List 1–3 assumptions we’re testing right now (e.g. “users prefer rule-based over ML for X”)
- [ ] If data this week contradicts an assumption → Did we already plan the pivot?
  - Document decision + next step in dated note / Git commit
- [ ] Identify one “nice-to-have” feature we can cut / delay to ship faster

## 3. Speed Levers Activated This Week (check all that apply)
- [ ] Automated deploy pipeline ran successfully (GitHub Actions / Vercel / similar)
- [ ] A/B test or feature flag deployed (even simple client-side toggle)
- [ ] Reduced scope of one ticket to ship same week
- [ ] Used no-code/low-code tool to prototype fast (Bubble, Softr, v0.dev, etc.)
- [ ] Outsourced non-core task (design, copy, simple integration) to free up dev time

## 4. Troll Irrelevance Score (quick gut check)
Rate 1–10 how different vCurrent is from v3 months ago:
- [ ] Feature set / UX flow
- [ ] Underlying tech stack or model architecture
- [ ] Data inputs / personalization logic
- Average score < 5? → You’re moving too slowly — raise urgency next week

## 5. Documentation & Proof (critical for AIA §273 prior user rights)
- [ ] Timestamped evidence added this week:
  - Git commit(s) with meaningful message
  - Dated screenshot / Loom video of new feature live
  - User feedback note (anonymized) with date
  - Internal design doc / Notion page updated
- Store in private repo / encrypted drive — never public

## 6. Next Week Acceleration Plan (3 min)
Write 1–3 concrete actions:
1.
2.
3.

Example:
1. Cut scope of analytics dashboard → ship basic version Monday
2. Run user poll on X about one pain point
3. Test new OSS model variant in staging

## Quick Wins to Keep Momentum
- Ship a tiny improvement every single week — even 1-line copy change counts
- Celebrate small velocity wins publicly (X thread, newsletter) → builds brand moat
- If stuck → ask: “What’s the smallest thing we can ship that still moves the needle?”

Print or copy this checklist into your weekly ritual doc.
Revisit monthly: Is our velocity increasing or plateauing?

Stay fast. Stay free.
