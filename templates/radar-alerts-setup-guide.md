# Radar Alerts Setup Guide
TrollProof Playbook – Industry-Specific Risk Radar

**Purpose:** Set up free, automated alerts to spot emerging patent threats, troll activity, or broad claims in your niche **before** they target you.
Early warning = early pivot = trolls get zero ROI.

**Time to Set Up:** 10–15 minutes (once) + 2 minutes/month maintenance
**Cost:** $0 (all tools free)
**Frequency:** Check dashboard weekly (during weekly-review-checklist.md)

**Recommended Tools (all free, no sign-up required for basics):**

1. Google Alerts (easiest + best coverage)
2. USPTO Patent Application Full-Text and Image Database (PatFT/AppFT) + RSS/Email watch
3. Google Patents Advanced Search + RSS feeds (optional)

**Step-by-Step Setup (Google Alerts – Primary Method)**

1. Go to: https://www.google.com/alerts

2. Create 4–8 targeted alerts (start with these, add more later):

   Alert 1: Core Niche + Patent
   Keywords: "[your niche] patent" OR "[your niche] patent troll" OR "[your niche] infringement"
   Example: "homeschool AI patent" OR "neurodivergent education patent" OR "adaptive learning patent troll"
   Options: Once a day, All results, RSS feed (optional)

   Alert 2: Broad AI/Tech + Your Niche
   Keywords: ("AI" OR "machine learning" OR "generative AI" OR "LLM") AND "[your niche]" AND (patent OR troll OR assertion OR demand)
   Example: ("AI" OR "LLM") AND "homeschool" AND (patent OR troll)

   Alert 3: §101 / Abstract Idea Trends
   Keywords: "§101" OR "Alice" OR "abstract idea" OR "patent ineligible" AND ("AI" OR "software" OR "your niche")
   Helps spot eligibility cases that weaken troll claims

   Alert 4: Known Trolls or Firms
   Keywords: "[known troll firm names]" OR "patent assertion entity" AND "[your niche]"
   (Add names as you learn them – e.g. "Intellectual Ventures" "IP Edge")

   Alert 5: Defensive Pub / Prior Art
   Keywords: "defensive publication" OR "prior art" AND "[your niche]" OR "[broad method keywords]"

   Alert 6: Funding / Competitor Watch (bonus)
   Keywords: "[your niche]" AND ("funding" OR "acquired" OR "lawsuit" OR "patent suit")

3. Delivery Settings (for each alert):
   - How often: Once a day (or As-it-happens if high-risk niche)
   - Sources: Automatic (includes news, web, blogs, patents)
   - Language: English (or add your language)
   - Region: Any region (or US + your target markets)
   - How many: Only the best results (reduces noise)
   - Deliver to: Your email (or RSS reader like Feedly/Inoreader)

4. USPTO Direct Watch (Advanced – Optional but Powerful)

   - Go to: https://ppubs.uspto.gov/pubwebapp/static/pages/landing.html
   - Use Patent Application Full-Text Search
   - Save search query: e.g. "adaptive learning" AND "artificial intelligence" AND ISD/20250101->20251231
   - Export RSS feed → add to RSS reader

5. RSS Reader Setup (Recommended for Zero Email Noise)

   - Use Feedly.com (free tier) or Inoreader.com
   - Add all Google Alerts RSS feeds
   - Add USPTO RSS if used
   - Create folder: "Patent Radar"
   - Scan weekly during review checklist

**Maintenance & Best Practices**

- Monthly: Review alerts → delete noisy ones, add new keywords (e.g. emerging buzzwords like "agentic AI" or "multimodal LLM")
- Weekly: Skim headlines → if red flag (new filing in niche), run quick scan-checklist.md
- Quarterly: Update keywords based on trends (e.g. if "prompt engineering patents" spike → add alert)
- Never click suspicious links — trolls sometimes use alerts to phish

**2025–2030+ Tips**
- AI patent filings exploding — add alerts for "prompt" "agent" "fine-tune" + niche
- Watch for PTAB IPR trends — add "PTAB" "IPR" AND "[your niche]"
- If international: Add "EPO" "WIPO" OR "European patent" alerts

**Quick Setup Checklist**
- [ ] Created 4+ Google Alerts
- [ ] Set to daily + best results
- [ ] Added to email or RSS reader
- [ ] Tested one alert (search yourself)
- [ ] Scheduled weekly 5-min scan in calendar

Once set — alerts run passively.
Early signal = free power.

Monitor quietly. Pivot early. Stay untouchable.
