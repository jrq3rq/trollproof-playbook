# Prior User Rights Log Template
TrollProof Playbook – Troll Deterrence Kit

**Purpose:** Create a simple, dated, continuous log to prove **prior user rights** under AIA §273 (35 U.S.C. §273).
This defense lets you keep using a process/machine you commercially used in the US **at least 1 year before** the patent's effective filing date — even if they later get a patent.

**Key Requirements for §273 Defense (2025+ rules):**
- You (or your company) commercially used the process/machine in the US **before** the patent's effective filing date.
- Use was **at least 1 year** before filing date.
- Proof must be **clear and convincing** (dated docs, witnesses, timestamps).
- Applies only to processes/machines (not compositions/articles of manufacture in most cases).
- Only protects the **specific** use/version — not expansions.

**How to Use This Log**
- Start **today** — backfill older evidence if possible.
- Add entries **every time** you ship, test commercially, or make internal use.
- Store privately (encrypted drive, secure Notion page, password-protected Git repo — never public).
- Include attachments: screenshots, code commits, invoices, user emails, dated videos.
- If sued → hand this to your attorney as first-line defense.

**Log Entry Format** (copy-paste for each new entry)

**Date:** [YYYY-MM-DD]
**Time (if relevant):** [HH:MM]
**Entry #:** [Sequential number, e.g. 001, 002…]

**Description of Use / Activity:**
[Detailed but concise: What was done? What version/feature/process? Who was involved? Was it commercial (sold, offered for sale, used in business) or qualifying internal use?]

Example:
"Released v0.3 of HomeschoolGuide.ai to 12 beta users. Feature: rule-based adaptive prompt generation for social stories based on parent profiles. Users paid $0 (beta free tier) but signed up via Stripe test mode. Deployed via Vercel at 14:32 PST."

**Evidence Attached / Referenced:**
- Git commit: [hash or link, e.g. abc1234 – "feat: add rule-based story gen"]
- Screenshot: [dated screenshot of live feature / dashboard]
- User count: [number]
- Other: [Loom video link, email receipt, internal memo dated today]

**Commercial Status:**
[ ] Internal qualifying use only
[ ] Offered for sale / used in business
[ ] Sold / revenue generated (even $1 counts)

**Witnesses / Verifiers (if applicable):**
- [Name / role, e.g. Co-founder JRQ3RQ – can confirm deployment]
- [Name / email – optional]

**Notes / Context:**
[Any additional details that strengthen proof, e.g. "This matches the process described in our internal design doc dated 2025-01-15."]

- [ ] Set recurring reminder: add entry weekly/monthly
- [ ] Store securely — encrypt folder, use 2FA on cloud storage

**2025–2030 Tips**
- Courts still require **clear and convincing** evidence — more docs = stronger defense
- Timestamp everything: Git commits, Notion page history, blockchain timestamps (OpenTimestamps)
- If international patents involved: §273 is **US-only** — foreign rights may be lost on public use
- Keep log factual — no exaggeration (could hurt credibility)
